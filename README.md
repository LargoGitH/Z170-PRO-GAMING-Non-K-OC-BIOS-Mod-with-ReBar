ReBar-Modded Non-K OC BIOS for Asus Z170 Pro Gaming

Enable 4G decoding in grub shell: "setup_var Setup 0x459 0x1"

THIS BIOS IS UNSTABLE AF!! (for me at least)
May need partial CSM ENABLED when enabling ReBar or it could black screen. (CSM off isn't a hard requirement for ReBar, it's just more convenient for setting 64 bit MMIO stuff)

Set BAR size with rebarstate.exe (https://github.com/xCuri0/ReBARUEFI)
